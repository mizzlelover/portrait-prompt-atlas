# Public release gate

The public repository is not a mirror of a scraped prompt corpus. A record becomes public only after all required gates pass.

| Gate | Required proof | Current corpus result |
| --- | --- | --- |
| Prompt attribution | Source post link, source publisher where available, and explicit authorship status | 728 / 728 complete |
| Source-image basis | Upstream CC BY 4.0 dataset source plus record-level X source link | 728 / 728 complete |
| Correction path | Issue template and correction / removal procedure present | Complete |
| Prompt evaluation | Rule-based triage plus a human result review | Rule-based triage complete; human review pending |
| Image pairing | One locally downloaded result image linked to each record | 728 / 728 complete |

## Why the gate is strict

An X permalink can identify a publisher, but it cannot establish that the publisher wrote the prompt or owns the generated image. This project therefore publishes the distinction itself: each record states whether the publisher is unverified or the provenance is unknown, and provides a correction/removal route.

## Release sequence

1. Review source post and thread.
2. Capture explicit author or repost-credit evidence.
3. Ask the creator for correction where the source is ambiguous.
4. Publish the source record with its actual attribution status; never infer an original author.
5. Correct or remove the record promptly when better evidence is supplied.

Every public record remains open to provenance review and correction.
