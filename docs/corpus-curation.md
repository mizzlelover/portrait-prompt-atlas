# 语料清理与分类 / Corpus curation

## 范围

原始发现池保存于 `data/raw-prompts.jsonl`，共 728 条。公开图鉴使用 `data/prompts.jsonl`，只保留“真人参考图驱动的人像处理”记录；不把产品海报、纯物体、食物、非人物角色或与真实人物编辑无关的案例混入人像库。

## 去重

去重不改写任何提示词。每条原文先做比较专用的标准化：去除 `Title:` / `Prompt:` 转发包装、参数默认值和标点差异，再以字符三元组 Dice 相似度聚类。仅当以下条件同时成立时才自动合并：

- Dice 相似度不低于 `0.94`；
- 较短提示词长度不低于较长提示词的 `85%`；
- 两条记录均在真人参考图处理范围内。

每个簇保留来源优先级更高、再按发布时间更早的记录。被剔除记录、保留记录、簇成员和相似度均写入 `data/curation-audit.json`，可复核且可恢复。

## 分类

分类基于“用户要完成的工作”，而非仅凭视觉风格。每条公开记录只有一个一级类别，同时带有可检索标签：

1. 修复与影像保全
2. 自然精修与美化
3. 职业头像与形象
4. 生活方式与旅行人像
5. 时尚与编辑肖像
6. 身份锁定风格转换
7. 纪念、家庭与关系影像
8. 创意肖像与场景表达

分类规则在 `scripts/curate-portrait-library.mjs` 中版本化。运行 `npm run curate:portrait-library` 后，再运行 `npm run generate:portrait-skill && npm test`；GitHub Actions 会拒绝未同步的派生文件。
