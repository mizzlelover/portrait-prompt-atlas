# 对标说明 / Benchmark

特别感谢 [苍何（freestylefly）](https://github.com/freestylefly) 创建的 [awesome-gpt-image-2](https://github.com/freestylefly/awesome-gpt-image-2)。其以开源图鉴、线上演示站和 Agent 使用方式组织 GPT Image 2 提示词库，直接启发本项目将已收集的人像处理资料整理为专精库与演示站。

本项目参考其开源产品结构，而不复制其提示词、文案、视觉设计或商业功能；本站的人像记录由本项目独立收集、筛选和维护。

| 能力 | 对标项目做法 | Portrait Prompt Atlas 实现 |
| --- | --- | --- |
| GitHub 首页 | 多语言导航、分类入口、线上图鉴、Skill 安装 | 中英说明、8 个人像业务分类、线上图鉴、安装入口 |
| 可视化站点 | 浏览案例、筛选、复制、跳转来源 | 519 条清理后人像记录、分类/身份控制筛选、原文复制、X 来源回链 |
| Agent Skill | Skill + 生成的参考索引 + CLI 安装 | Skill + 519 条随包记录 + CLI 搜索/查看/统计 + 本地安装器 |

## 有意不同的地方

1. 本项目专注人像处理，而非全品类图像生成。
2. 提示词永久保留来源语言；界面与说明提供中文，而不翻译被收录的提示词。
3. 署名、来源与更正机制是主数据模型的一部分：发布者不等于原创作者。
4. 当前不接入付费生成、登录、积分或模型 API。它们需要单独的用户隐私、支付、内容审核与运营授权，不能把“图鉴”直接扩展成代用户生成的服务。

## 当前 Skill 的完整性

原先的 Skill 只能描述人工选择流程，不能独立复用研究库。升级后的包内携带完整记录索引，安装后无需依赖仓库根目录；它可检索、展示单条完整提示词、保留逐字哈希、输出来源边界，并可由生成器随主库更新。`npm test` 验证所有收录提示词在网站、Skill 和研究主库之间保持一致。
